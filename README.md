# Тихо — дневник воспоминаний

Публичная версия сайта: <https://taimasv.github.io/art-tech-optional/>

## Публикация

GitHub Actions публикует файлы сайта в GitHub Pages при каждом push в `main`.
Если Pages ещё не включён в репозитории, откройте **Settings → Pages** и выберите
**Source: GitHub Actions**. После первого успешного запуска workflow сайт будет
доступен по ссылке выше.

GitHub Pages размещает статический сайт. Записи гостя и загруженное аудио
хранятся в браузере. Для регистрации с хранением данных аккаунта на сервере
нужно дополнительно развернуть `server.js` на Node.js-хостинге.

## Локальный запуск

```sh
npm run dev
```

Затем откройте <http://localhost:3000/>.
