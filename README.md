# «Тихо» — дневник атмосферы

«Тихо» превращает историю дня, настроение, фотографию и музыку в визуальное воспоминание. Архив помогает вернуться к записи и найти её по словам.

## Правила визуальной системы

- Настроение задаёт эмоциональную палитру карточки.
- Слова истории определяют один из визуальных мотивов: вода, дорога, природа, свет или дом.
- Фотография становится фоном записи; музыка или аудиофайл сохраняются рядом с ней.
- Антиква в заголовках, дата, подпись и музыкальная строка объединяют дни в цельную ленту.
- Фоновые Canvas-волны реагируют на движение указателя и касание.

Это художественные правила прототипа, а не психологический анализ пользователя.

## Запуск локально

Нужен Node.js 18 или новее. В корне проекта выполните:

```sh
npm run dev
```

Откройте <http://localhost:3000/>. Статическую версию можно открыть по ссылке [taimasv.github.io/art-tech-optional](https://taimasv.github.io/art-tech-optional/). В браузере записи гостя сохраняются локально; серверный вход доступен при запуске `server.js`.

## Код и стек

- `art.html`, `art.css`, `art.js` — интерфейс, дизайн и логика дневника.
- `demo-days.js` — три отдельные демонстрационные записи; они не попадают в личное хранилище.
- `grain-backdrop.js`, `waveform-player.js`, `circuit-flash.js` — анимированный фон, аудиоволна и интерактивная графика архива.
- `music-library.js`, `server.js` — поиск музыки и локальный API.
- `index.html` — входная страница GitHub Pages.

Публикация GitHub Pages запускается GitHub Actions при обновлении `main`.
