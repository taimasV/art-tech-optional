# «Тихо» — дневник атмосферы

«Тихо» помогает сохранить не только события дня, но и то, как он ощущался. Пользователь записывает короткую историю, выбирает настроение, добавляет фотографию и песню. Дневник собирает их в визуальное воспоминание, которое можно открыть, найти и пересмотреть в архиве.

Ввод влияет на образ по понятным правилам: настроение задаёт цветовую атмосферу, слова в истории выбирают мотив — воду, дорогу, природу, свет или дом, фотография становится фоном, а музыка и загруженное аудио остаются частью записи. Единая типографика и композиция связывают разные дни, сохраняя различия между ними. В архиве также есть три явно помеченных демонстрационных дня; они не смешиваются с личными записями.

Прототип работает в браузере на HTML, CSS и JavaScript. Локальные записи хранятся в браузере, а локальный Node.js-сервер добавляет API для аккаунта и музыкального поиска. Фоновые волны реагируют на движение указателя и касание. Это художественный дневник, а не психологическая оценка настроения.
